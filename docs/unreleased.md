# 1.0.0-alpha.1 — unpublished candidate

本次目标仅为官方 DSH 0.2.2-rc.1（66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db，Cordis 4.1.0）。旧六版验收不自动覆盖本次修改；公开稳定版仍是 0.1.20，支持窗口见 stable 分支。

- 普通图片点击、预览、拖放与常规操作使用官方能力。
- 通过公开 contextMenus 的 image 类型添加“标注图片”，不截获全局点击，不解析官方图片 DOM 或复制官方图库。
- 仅显式打开所选图片；保留标注所需的缩放、拖动、备注和导出，以及可选 nativeImageViewer 服务供主动调用。
- 标注使用官方附件与草稿接口，不自动发送；异步准备可取消，已有草稿与备注保留。
- 不预装进 Portable，不修改官方安装包。

RC1 Windows 隔离 UI 验收：passed（生成会话与图片；普通草稿预览、会话图片菜单、缩放/拖动、备注、原图下载、Escape/焦点、标注返还原草稿均通过）。不代表已验证用户现有安装、官方签名桌面包装或真实模型调用。本次不发布。
